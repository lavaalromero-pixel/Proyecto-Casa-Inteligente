📐 Fase de Diseño del Prototipo

1. Esquemático con ESP32

El sistema está basado en una tarjeta ESP32 que actúa como controlador principal. El sensor MQ-135 se conecta a una entrada analógica para medir la calidad del aire. El sensor ultrasónico HC-SR04 se conecta a dos pines digitales para medir distancias y detectar presencia de personas u objetos. El módulo HW-080 se utiliza para complementar las funciones de monitoreo del sistema. Todos los dispositivos están conectados a la ESP32, que procesa la información y ejecuta acciones automáticas dentro de la vivienda.

2. Dibujos y detalles constructivos del prototipo

El prototipo representa una vivienda inteligente a escala elaborada en cartón, madera MDF o material reciclable. En el interior se ubican los sensores y el ESP32. El MQ-135 se coloca en una zona de ventilación para detectar gases o contaminación. El HC-SR04 se instala en la entrada principal para detectar la presencia de personas. La estructura contará con espacios para el cableado y la fuente de alimentación.

3. Materiales requeridos

  • ESP32
  • Sensor MQ-135
  • Sensor ultrasónico HC-SR04
  • Módulo HW-080
  • Protoboard
  • Cables Dupont
  • LEDs indicadores
  • Resistencias
  • Fuente de alimentación USB 5V
  • Cartón o MDF para la maqueta
  • Silicona y herramientas de montaje

4. Diseño estructural del sistema técnico

  • Entrada de datos: sensores MQ-135, HC-SR04 y HW-080.
  • Procesamiento: ESP32 recibe y analiza la información de los sensores.
  • Salida: activación de LEDs, alarmas o notificaciones según las condiciones detectadas.

5. Mecanismos, sensores y actuadores

Sensores

  • MQ-135: monitorea la calidad del aire y detecta gases contaminantes.
  • HC-SR04: mide distancias y detecta movimiento o presencia.
  • HW-080: proporciona información adicional para el monitoreo del sistema.

Actuadores

  • LEDs de señalización.
  • Posibles alarmas o sistemas de ventilación automatizados.

6. Fuentes de energía

El sistema será alimentado mediante una fuente USB de 5V conectada al ESP32. Esta alimentación suministra energía a todos los sensores y componentes electrónicos del prototipo.

7. Control y programación

El control del sistema se realizará mediante programación en Arduino IDE utilizando el ESP32. El programa leerá continuamente los datos de los sensores y ejecutará acciones automáticas según las condiciones establecidas.

Funciones principales:

  • Monitoreo de calidad del aire.
  • Detección de presencia y distancia.
  • Activación de alertas visuales.
  • Procesamiento de datos en tiempo real.

8. Diseño electrónico

El diseño electrónico está compuesto por el ESP32 como unidad central de control, conectado al MQ-135 mediante una entrada analógica y al HC-SR04 mediante pines digitales de Trigger y Echo. Los LEDs se conectan a salidas digitales para indicar el estado del sistema. Todo el circuito se monta sobre una protoboard para facilitar pruebas y modificaciones.
