📖 Acerca del Proyecto

Definición del Proyecto

La casa domótica es un proyecto de automatización diseñado para controlar y monitorear diferentes funciones del hogar mediante sensores electrónicos y un microcontrolador ESP32.

El sistema utiliza el sensor HC-SR04 para detectar distancias y movimientos, el sensor MQ-135 para detectar gases y controlar la calidad del aire, y el módulo HW-080 para apoyar funciones de detección y automatización dentro de la vivienda.

La información obtenida por los sensores es procesada por el ESP32, permitiendo ejecutar acciones automáticas como activar alarmas, encender luces o generar avisos de seguridad según las condiciones detectadas.

Este proyecto busca mejorar la seguridad, comodidad y eficiencia del hogar mediante el uso de tecnologías inteligentes, aplicando conocimientos de programación, electrónica y automatización.

Soluciones Existentes

  • Google Home: Permite controlar dispositivos inteligentes mediante comandos de voz y automatizar tareas del hogar.
  • Amazon Alexa: Integra sensores y dispositivos para controlar luces, puertas, cámaras y electrodomésticos.
  • Samsung SmartThings: Plataforma que conecta diferentes dispositivos inteligentes para automatizar funciones dentro de una vivienda.
  • Sistemas de monitoreo ambiental: Utilizan sensores de gases para detectar contaminación, humo o sustancias nocivas en espacios cerrados.

ESP32 y Programación

Para el desarrollo de la casa domótica se utilizará el ESP32, un microcontrolador de bajo costo y alto rendimiento diseñado para proyectos de automatización e Internet de las Cosas (IoT).

Características del ESP32

  • Procesador de 32 bits de alto rendimiento.
  • Conectividad Wi-Fi y Bluetooth integrada.
  • Gran cantidad de pines GPIO.
  • Bajo consumo de energía.
  • Compatible con diversos sensores electrónicos.
  • Programable mediante Arduino IDE.

Funciones Principales

Setup(): Se ejecuta una sola vez al iniciar el dispositivo y permite configurar sensores, comunicación serial y pines.

Loop(): Se ejecuta continuamente para leer sensores y tomar decisiones automáticas.

Sensores Utilizados

Sensor MQ-135

  • Detecta amoníaco.
  • Detecta dióxido de carbono.
  • Detecta humo.
  • Monitorea la calidad del aire.

Cuando aumenta la concentración de gases, el sensor genera una señal que es interpretada por el ESP32.

Sensor HW-080

  • Detecta incendios.
  • Activa alarmas preventivas.
  • Mejora la seguridad del hogar.

Detecta la radiación infrarroja emitida por una llama y envía una señal al microcontrolador.

Sensor HC-SR04

  • Detecta presencia de personas.
  • Mide proximidad de objetos.
  • Automatiza puertas o iluminación.

Funciona mediante ondas ultrasónicas que rebotan en los objetos y permiten calcular la distancia.

Diseño y Funcionamiento del Sistema

El proyecto consiste en una casa domótica controlada por un ESP32, encargado de recibir, procesar y gestionar la información de los sensores instalados en la vivienda.

Componentes Principales

  • ESP32 como controlador principal.
  • Sensor MQ-135 para calidad del aire.
  • Sensor HW-080 para detección de fuego.
  • Sensor HC-SR04 para detección de personas y objetos.
  • LEDs y alarmas para notificaciones de riesgo.

Funcionamiento

  1. El MQ-135 supervisa la calidad del aire y genera alertas cuando detecta gases o humo.
  2. El HW-080 detecta llamas y activa alarmas visuales o sonoras.
  3. El HC-SR04 detecta personas u objetos para automatizar funciones del hogar.
  4. El ESP32 procesa toda la información y ejecuta las acciones programadas.
